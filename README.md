# Datheon Machine Learning Internship Projects

## Task 1: Multi-Class Classification
- Dataset: Iris CSV
- Models: Logistic Regression and Decision Tree
- Metrics: Accuracy, Precision, Recall, F1-score
- Visualizations: Confusion matrices and species pairplot
- Notebook: `Task1_Iris_Classification.ipynb`

## Task 2: Housing Price Prediction
- Dataset: California Housing (`housing.csv`)
- Models: Ordinary Least Squares (OLS), Ridge and Lasso Regression
- Features: Data preprocessing and interaction features
- Metrics: RMSE, MAE and R²
- Visualizations: Actual vs predicted values and residual analysis
- Notebook: `Task2_Housing_Price_Prediction.ipynb`
